Introdução

Markdown é uma linguagem de marcação leve usada para formatar texto. Foi criada por John Gruber em 2004 e desde então se tornou amplamente adotada, especialmente nas áreas de criação de conteúdo web, aplicativos de anotações e sistemas de controle de versão como Git.

Markdown permite que os usuários escrevam conteúdo usando uma sintaxe simples que pode ser facilmente convertida em HTML ou outros formatos. Isso o torna uma excelente escolha para formatar texto em editores de texto simples, documentos online, arquivos README e muitos outros contextos onde se deseja uma marcação legível e leve.

Primeiros Passos

Sintaxe básica para começar a usar o formato markdown.

Títulos

  • Título 1: # Título 1 ou ## Título 1

  • Título 2: ## Título 2 ou ### Título 2

  • Título 3: ### Título 3 ou #### Título 3

Ênfase

  • Negrito: **Texto em negrito** ou __Texto em negrito__

  • Itálico: *Texto em itálico* ou _Texto em itálico_

  • Negrito Itálico: ***Texto em negrito itálico*** ou ____Texto em negrito itálico____

  • ~~Riscado~~: ~~Texto riscado~~

Listas

  • Lista Não Ordenada:

- Item 1
- Item 2
  - Item aninhado 2.1

  • Lista Ordenada:

1. Item 1
2. Item 2
   1. Item aninhado 2.1

Links

  • Link inline: [Texto do link](https://www.exemplo.com)

  • Link de referência:

[Texto do link][id-do-link]

[id-do-link]: https://www.exemplo.com

Imagens

  • Imagem inline:

![Texto alternativo](url_da_imagem "Título opcional")

Citações em bloco

> Esta é uma citação em bloco.
>
> > Esta é uma citação em bloco aninhada.

Código inline

  • Envolva com acentos graves: `código inline`

Blocos de código

  • Recue cada linha com 4 espaços ou use três acentos graves ` para abrir o bloco de código e três para fechá-lo.

Regras horizontais

  • Três ou mais

Tabelas

Para criar tabelas no formato Markdown, você pode usar pipes (|) para colunas e traços - ou outros caracteres como = ou _ para linhas entre células. Veja como você pode criar diferentes tipos de tabelas:

Tabela simples com uma única linha acima e abaixo:

| Cabeçalho 1 | Cabeçalho 2 |
|----------|----------|
| Célula 1   | Célula 2   |
| Célula 3   | Célula 4   |

Saída:

Cabeçalho 1

Cabeçalho 2

Célula 1

Célula 2

Célula 3

Célula 4

Célula 3

Célula 4
