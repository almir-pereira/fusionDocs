Instalação Rápida


Bem-vindo ao guia de instalação do FusionPBX.


O FusionPBX pode ser instalado em vários sistemas operacionais diferentes. No entanto, este guia assume que você está começando com uma instalação mínima do Debian 12 com SSH habilitado. Esta instalação foi projetada para ser rápida, simples e modular, e geralmente leva 5 minutos ou menos. Os tempos de instalação dependem de fatores como CPU, RAM, I/O de disco e largura de banda. Vídeo de instalação: https://youtu.be/XpiVyHqLaus

1. Execute os seguintes comandos como root. O script instala FusionPBX, o pacote de release do FreeSWITCH e suas dependências, iptables, Fail2ban, NGINX, PHP-FPM e PostgreSQL.

Comece com uma instalação mínima do Debian 12 com SSH habilitado. Cole os seguintes comandos na janela do console um por vez.

    wget -O - https://raw.githubusercontent.com/fusionpbx/fusionpbx-install.sh/master/debian/pre-install.sh | sh; 


    cd /usr/src/fusionpbx-install.sh/debian && ./install.sh

Se estiver usando Debian em containers Proxmox LXC, execute o seguinte ANTES de iniciar a instalação do FusionPBX.

    apt-get update && apt-get upgrade
    apt-get install systemd
    apt-get install systemd-sysv
    apt-get install ca-certificates
    reboot

2. Ao final da instalação, o script instruirá você a acessar o endereço IP do servidor (ou nome de domínio) no seu navegador web para fazer login. O script também fornecerá um nome de usuário e uma senha aleatória segura para você usar. Isso pode ser alterado após o login. O script de instalação cria o banco de dados fusionpbx. Se você precisar da senha do banco de dados, ela está localizada em /etc/fusionpbx/config.php .

    Instalação concluída.

    Use um navegador web para fazer login.
       nome de domínio: https://000.000.000.000

    O nome de domínio no navegador é usado por padrão como parte da autenticação.
    Se você precisar fazer login em um domínio diferente, use usuário@dominio.

Após a conclusão do script de instalação, vá para o seu navegador web e faça login com as informações fornecidas pelo script de instalação.

Após a conclusão do script de instalação, a opção para qualquer coisa se registrar no endereço IP está HABILITADA.

  • Se você

``` plan on registering devices to the FusionPBX ip address then no further action is required.

No entanto, é recomendável registrar-se a um nome de domínio (FQDN), pois a maioria dos ataques automatizados ocorre contra o IP público. Registrar-se ao endereço IP será bloqueado pelas regras do fail2ban freeswitch-ip e auth-challenge quando essas regras estiverem definidas como true.

  • Para ajudar a proteger sua instalação do FusionPBX, habilite as regras do fail2ban [freeswitch-ip] e [auth-challenge-ip] em /etc/fail2ban/jail.local.

[freeswitch-ip]
enabled  = true

[auth-challenge-ip]
enabled  = true
