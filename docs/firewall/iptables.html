Salvar Regras em rules.v4

Isso salva as regras ativas do iptables no arquivo rules.v4.

iptables-save > /etc/iptables/rules.v4

Bloquear User Agent SIP

Bloqueia o User Agent VaxSIPUserAgent/3.1 nas portas 5060 e 5080.

iptables -I INPUT -j DROP -p udp --dport 5060 -m string --string "VaxSIPUserAgent/3.1" --algo bm
iptables -I INPUT -j DROP -p udp --dport 5080 -m string --string "VaxSIPUserAgent/3.1" --algo bm
iptables -I INPUT -j DROP -p tcp --dport 5080 -m string --string "VaxSIPUserAgent/3.1" --algo bm

Adicionar Regras DSCP

iptables -t mangle -A OUTPUT -p udp -m udp --sport 16384:32768 -j DSCP --set-dscp 46 
iptables -t mangle -A OUTPUT -p udp -m udp --sport 5060:5091 -j DSCP --set-dscp 26 
iptables -t mangle -A OUTPUT -p tcp -m tcp --sport 5060:5091 -j DSCP --set-dscp 26

Exibir Regras do Iptables

sudo iptables -L -v

Exibir Números de Linha

iptables -L -v -n --line-numbers

Exibir Regras DSCP

iptables -vL -t mangle

Excluir uma Linha

Excluir linha 2

iptables -D INPUT 2

Limpar Iptables

iptables -P FORWARD ACCEPT
iptables -P OUTPUT ACCEPT
iptables -F

Abrir uma Porta para um Endereço IP Específico

iptables -A INPUT -j ACCEPT -p tcp --dport 5432 -s x.x.x.x/32

Bloquear Endereço IP

iptables -I INPUT -s 62.210.245.132 -j DROP

Restaurar Regras do rules.v4

Isso lê o arquivo rules.v4 e carrega as regras salvas do iptables de volta na memória ativa.

iptables-restore < /etc/iptables/rules.v4

Limpar iptables

Como limpar iptables sem perder o acesso ao ssh.
