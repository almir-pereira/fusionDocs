Provisionamento

Automático

O provisionamento automático está desabilitado por padrão. Isso é para dar uma chance de proteger o servidor de provisionamento com Autenticação HTTP ou CIDR. A Autenticação HTTP exige que o telefone envie o hash do nome de usuário e senha combinados para obter a configuração. CIDR é uma restrição de endereço IP que pode ser usada para restringir quais endereços IP têm permissão para obter a configuração do dispositivo. Um exemplo de CIDR é xxx.xxx.xxx.xxx/32, onde /32 representa um único endereço IP. Para definir um desses valores, vá para Avançado > Configurações Padrão e encontre a categoria Provisionamento a partir daí, use o botão editar para definir um valor. Depois que isso for feito, é seguro definir enabled como true.

Navegue até Avançado > Configurações Padrão

Selecione Provisionamento na lista de categorias, existem algumas opções-chave que precisam ser definidas para ativar o provisionamento automático.

  • enabled Deve estar habilitado e definido como value true e enabled True. Está desabilitado por padrão.

  • http_auth_username Deve estar habilitado e definido como value true e enabled True. Está desabilitado por padrão. Certifique-se de usar um nome de usuário forte.

  • http_auth_password Deve estar habilitado e definido como value true e enabled True. Está desabilitado por padrão. Certifique-se de usar uma senha forte.

  • cidr Opção de segurança opcional para permitir que solicitações de configuração sejam limitadas a faixas específicas de IP versão 4. O tipo array permite múltiplas faixas de endereços IP.

Catálogo Telefônico

O catálogo telefônico remoto (Agenda de Endereços) é baseado no Aplicativo de Contatos do FusionPBX.

Configurações do Catálogo Telefônico

Para usar o catálogo telefônico, algumas etapas são necessárias.

  • Atribua o dispositivo a um usuário.

  • Crie ou importe os Contatos.

  • Defina Enabled como True em Configurações Padrão.

  • Defina Enabled True para contact_extensions, contact_users e contact_groups em Configurações Padrão.

  • No telefone, acesse o menu para atualizar o catálogo telefônico.
