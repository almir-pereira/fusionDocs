Fail2ban

O Fail2ban também é usado para proteger SSH, FreeSWITCH, o servidor web, bem como outros serviços.

Após a conclusão do script de instalação, a opção para qualquer coisa se registrar no endereço IP está HABILITADA.

  • Se você planeja registrar dispositivos no endereço IP do FusionPBX, nenhuma ação adicional é necessária.

No entanto, é recomendável registrar-se em um nome de domínio (FQDN), já que a maioria dos ataques automatizados ocorre no IP público. Registrar-se no endereço IP será bloqueado pelas regras do fail2ban freeswitch-ip e auth-challenge quando essas regras estiverem definidas como true.

  • Para ajudar a proteger sua instalação do FusionPBX, habilite as regras do fail2ban [freeswitch-ip] e [auth-challenge-ip] em /etc/fail2ban/jail.local.

[freeswitch-ip]
enabled  = true

[auth-challenge-ip]
enabled  = true

Aviso

Se você perceber que a interface web do FusionPBX não está carregando, verifique se o fail2ban está bloqueando seu IP. Ser bloqueado por qualquer regra do fail2ban bloqueará ssh, www e o registro de telefones se você não tiver seu IP no campo ignoreip= do /etc/fail2ban/jail.conf.

Você pode visualizar os endereços IP bloqueados pelo Fail2ban com o seguinte comando.

iptables -L -n

Para verificar o status de uma das jails do fail2ban

fail2ban-client status freeswitch-ip

Os arquivos de configuração do Fail2ban estão localizados em.

cd /etc/fail2ban/

Para excluir um IP para que ele não seja bloqueado por nenhum filtro, edite o arquivo jails.conf.

nano /etc/fail2ban/jail.conf

Encontre ignoreip e adicione o endereço IP, CIDR ou hostname DNS que precisam ser colocados na lista de permissões. Use um espaço como delimitador entre cada um. Reinicie o fail2ban para aplicar as alterações na lista ignoreip.

ignoreip = 127.0.0.1/8 192.168.0.0/16

Nota

Para ajudar a manter os IPs e hostnames que você deseja desbloqueados, é uma boa ideia adicionar clientes e operadoras à lista ignoreip.

Os filtros são definidos no seguinte diretório.

/etc/fail2ban/filter.d

Dentro do jail.local, ele aponta para filtros e define maxretry, bantime, logpath, portas a serem bloqueadas e muito mais.

/etc/fail2ban/jail.local

Limpe todos os endereços bloqueados reiniciando o fail2ban.

service fail2ban restart

O Fail2ban registra os endereços que bloqueia com o filtro que o acionou.

/var/log/fail2ban.log

Mais informações sobre o Fail2ban podem ser encontradas em http://www.fail2ban.org/wiki

Nota

Você pode usar um serviço de endereço IP dinâmico como o dyndns para colocar na lista de permissões um endereço IP dinâmico.
