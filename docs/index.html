FusionPBX

Um projeto de código aberto que fornece uma interface web personalizável e flexível para o poderoso e altamente escalável switch de voz multiplataforma chamado FreeSWITCH.

O FusionPBX funciona em diversos sistemas operacionais (otimizado para Debian & Ubuntu) e no hardware de sua escolha. O FusionPBX oferece uma interface multi-inquilino, provisionamento de telefones, ramais ilimitados, transcrição de gravações de chamadas, correio de voz por e-mail, transcrição de correio de voz, conversão de texto em fala para gravações, filas de call center, música em espera, estacionamento de chamadas, linhas analógicas ou circuitos T1/E1 de alta densidade, e muitos outros recursos. O FusionPBX fornece a funcionalidade que as empresas precisam e oferece recursos de sistema telefônico de nível corporativo para pequenas, médias e grandes empresas. Clique aqui para o canal do FusionPBX no YouTube.

Benefícios do FusionPBX

  1. Adiciona funcionalidades extras à incrivelmente robusta plataforma VoIP FreeSWITCH.

  2. Torna o FreeSWITCH fácil de administrar, ao mesmo tempo que permite trabalhar diretamente na Interface de Linha de Comando do FreeSWITCH (fs_cli) quando necessário.

  3. Oferece aos seus usuários e inquilinos uma interface gráfica (GUI) atraente para interagir.
