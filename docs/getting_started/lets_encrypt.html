Let’s Encrypt

Let’s Encrypt é uma das formas mais recentes e amplamente utilizadas de segurança SSL gratuita e suporta DNS curinga. Você pode usar o Let’s Encrypt com sua instalação do FusionPBX e WebRTC, como o Verto Communicator.

Dehydrated (Recomendado)

O FusionPBX possui uma opção para instalar SSL de forma fácil e rápida com o Let’s Encrypt usando o letsencrypt.sh. Com este script, você pode escolher solicitar um certificado SSL curinga (*.dominio.tld) ou para nomes de host (dominio.tld).

O letsencrypt.sh fará o seguinte:

  • Baixar o dehydrated.

  • Solicitar um certificado SSL do Let’s Encrypt.

  • Configurar o NGINX para usar o certificado SSL.

  • Combinar e colocar o certificado SSL no diretório apropriado do FreeSWITCH para uso de TLS.

  • Testar e garantir que o certificado SSL funcione e exibir a saída se for bem-sucedido.

Usando letsencrypt.sh

Com o letsencrypt.sh, você tem a opção de criar um certificado SSL para um único domínio (dominio.tld), vários subdomínios (sub.dominio.tld, sub1.dominio.tld, etc.dominio.tld) ou curinga (*.dominio.tld). A maneira mais fácil, no entanto, é usar o método de nome de host.

Nome do Host

Para criar um certificado SSL para um nome de host ou vários nomes de host, vá para:

cd /usr/src/fusionpbx-install.sh/debian/resources/

Em seguida, execute o script.

./letsencrypt.sh

Você deve então ver e seguir as instruções.

Domain Name: dominio.tld
Email Address: suporte@fusionpbx.com

Depois disso, você deve ver a seguinte saída.

Nota

Ao definir o registro txt com seu registrador de domínio, certifique-se de usar a saída do script que você está executando e não o que está neste exemplo.

Add the following to the zone definition of dominio.tld:
_acme-challenge.dominio.tld. IN TXT "PY7ttk6no_5eG7WtAbO6qs5-NzA-Kigko375omKc0nw"

Dica

Use o comando dig para verificar se o registro txt está correto.

dig -t txt _acme-challenge.dominio.tld

A saída deve mostrar:

;; ANSWER SECTION: _acme-challenge.dominio.tld. 1799 IN TXT “PY7ttk6no_5eG7WtAbO6qs5-NzA-Kigko375omKc0nw”
