Auto Provision de Telefones

O auto provisionamento está desabilitado por padrão. Isso é para dar uma chance de proteger o servidor de provisionamento com Autenticação HTTP ou CIDR. A Autenticação HTTP exige que o telefone envie um hash do nome de usuário e senha combinados para obter a configuração. CIDR é uma restrição de endereço IP que pode ser usada para restringir quais endereços IP têm permissão para obter a configuração do dispositivo. Um exemplo de CIDR é xxx.xxx.xxx.xxx/32, onde o /32 representa um único endereço IP. Para definir um desses valores, vá em Avançado > Configurações Padrão e encontre a categoria Provision. A partir daí, use o botão de edição para definir um valor. Após isso, é seguro definir enabled como true.
