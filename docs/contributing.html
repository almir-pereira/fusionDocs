Contribuindo

Existem muitas maneiras de ajudar o projeto FusionPBX.

O Que Precisamos

  1. Desenvolvedores

  2. Redatores Técnicos

  3. Tradutores

  4. Testadores de Garantia de Qualidade

  5. Documentadores

Nota

Se você planeja contribuir para qualquer um de nossos repositórios no GitHub, exigimos que você assine
o Contrato de Licença do Contribuidor FusionPBX. Isso protege principalmente o FusionPBX e nossos usuários de códigos que possam ser inseridos e que possam representar um problema legal. Ele faz isso verificando se o código que você está
contribuindo é seu para doar e que você o doa livre e irrevogavelmente ao projeto.

Como Começar

  1. Assista ao vídeo do YouTube “FusionPBX Pull Requests with GitHub”: https://youtu.be/SPUe7S4Z6ms

  2. Se você tem um bom domínio de PHP, Lua ou SQL, o desenvolvimento pode ser a sua praia. Vá para o Manual de Desenvolvimento.

  3. Você é um usuário avançado do FusionPBX e talvez ame escrever? Confira o Guia de Documentação ou o Guia de Testes.

  4. Gostaria de ver o FusionPBX no seu idioma nativo e tem tempo para se comprometer a manter as traduções atualizadas para os lançamentos?
    Confira a seção de tradução para aprender como usar nosso servidor de tradução.

Nota

Contribuir com código ou documentação requer conhecimento de Git, GitHub e como criar pull requests no GitHub.
Isso não é tão difícil quanto parece, e se você estiver disposto a aprender, nós o ajudaremos nesse processo.
