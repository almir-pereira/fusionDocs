Idiomas

O FusionPBX possui capacidades multilíngues. Isso permite que diferentes idiomas sejam usados na sua instalação do FusionPBX. Os idiomas podem ser definidos globalmente, por tenant e por usuário. Além da interface web da sua instalação do FusionPBX, existem opções para enviar arquivos de áudio para o FreeSWITCH usar via linha de comando.

Configurações do FusionPBX

Global

Avançado > Configurações Padrão

Definir o idioma a partir daqui definirá o idioma para toda a instalação do FusionPBX.

Domínio (Tenant)

Avançado > Domínios e clique no sinal de mais no canto inferior direito e preencha os campos obrigatórios.

Definir o idioma a partir daqui definirá o idioma para todo o domínio (tenant) na sua instalação do FusionPBX. Isso pode substituir as configurações de idioma Global.

Usuário

Contas > Usuários e edite o usuário.

Definir o idioma a partir daqui definirá o idioma para este usuário específico e substituirá as configurações de idioma Global e de Domínio.

Arquivos de Som do FreeSWITCH

A localização dos arquivos de som do FreeSWITCH depende do sistema operacional e do método de instalação.

Instalação por Pacote

  • A maioria, senão todas, as instalações recentes do FusionPBX usam pacotes para o FreeSWITCH.

  • Localização no sistema de arquivos:

/usr/share/freeswitch/sounds/en/us/

Instalação por Fonte

  • Instalações antigas, instalações personalizadas ou preferência pessoal usam versões compiladas a partir da fonte.

  • Localização no sistema de arquivos:

/usr/local/freeswitch/sounds/en/us/

Onde obter sons de idioma

  • Grátis: https://freeswitch.org/stash/projects/FS/repos/freeswitch-sounds/browse

app_languages.php

Diretrizes As palavras usadas no nome da variável de texto

  • separadas por um traço.

  • começam com um prefixo

  • estão em letras minúsculas

Prefixos

  • title: O título da página

  • header: O cabeçalho da página

  • description: Informação para descrever a página ou um item na página

  • button: O rótulo para os botões

  • confirm: Uma mensagem usada para confirmar uma ação como excluir

  • message: A resposta após uma ação ser realizada

  • label: O rótulo para itens na página

  • option: As opções em uma caixa de seleção HTML

Idiomas

Cada palavra, frase ou sentença tem o idioma declarado com o código de 2 letras do idioma com um traço separando a região. Há uma diferença: a região está inteiramente em letras minúsculas. Para informações adicionais, veja o seguinte.

http://www.w3.org/International/articles/language-tags/

http://www.iana.org/assignments/language-subtag-registry

  • en-us

  • es-mx

  • de-ch

  • de-at

  • fr-ca

  • fr-ch

  • pt-pt

  • pt-br

   $text['label-edit']['pt-pt'] = '';

Para usar dentro do código em cada página que exibe texto. Coloque o seguinte código no topo, logo após o permission_exists

//adiciona suporte multilíngue
   require_once "app_languages.php";
   foreach($text as $key => $value) {
       $text[$key] = $value[$_SESSION['domain']['language']['code']];
   }

Para colocar uma palavra, frase ou sentença, ela seria usada no código como no exemplo a seguir.

echo "<td align='left' width='30%' nowrap='nowrap'><b>".$text['title-conference-centers']."</b></td>\n";

echo " <tr>\n";
echo "     <td align='left' colspan='2'>\n";

echo " </tr>\n";
echo "</table>\n";
