Backup

É sempre bom ter um método de backup implementado. Aqui estão os passos para um método básico de backup com o FusionPBX. O script de instalação no Debian copiará automaticamente este script de backup para /etc/cron.daily/fusionpbx-backup. Os backups são armazenados em /var/backups/fusionpbx/postgresql por padrão.

Linha de Comando

Certifique-se de alterar a senha substituindo o zzzzzzzz em PGPASSWORD="zzzzzzzz" pela senha do seu banco de dados. Você pode obter a senha em /etc/fusionpbx/config.php.

    cd /etc/cron.daily
    nano fusionpbx-backup

    #!/bin/sh

    export PGPASSWORD="zzz"
    db_host=127.0.0.1
    db_port=5432

    now=$(date +%Y-%m-%d)
    mkdir -p /var/backups/fusionpbx/postgresql

    echo "Backup Iniciado"

    #deletar backups do postgres
    find /var/backups/fusionpbx/postgresql/fusionpbx_pgsql* -mtime +4 -exec rm {} \;

    #deletar o backup principal
    find /var/backups/fusionpbx/*.tgz -mtime +2 -exec rm {} \;

    #backup do banco de dados
    pg_dump --verbose -Fc --host=$db_host --port=$db_port -U fusionpbx fusionpbx --schema=public -f /var/backups/fusionpbx/postgresql/fusionpbx_pgsql_$now.sql

    #empacotar
    #tar --exclude='/var/lib/freeswitch/recordings/*/archive' -zvcf /var/backups/fusionpbx/backup_$now.tgz /var/backups/fusionpbx/postgresql/fusionpbx_pgsql_$now.sql /var/www/fusionpbx /usr/share/freeswitch/scripts /var/lib/freeswitch/storage /var/lib/freeswitch/recordings /etc/fusionpbx /etc/freeswitch /usr/share/freeswitch/sounds/music/

    #fonte
    #tar -zvcf /var/backups/fusionpbx/backup_$now.tgz /var/backups/fusionpbx/postgresql/fusionpbx_pgsql_$now.sql /var/www/fusionpbx /usr/local/freeswitch/scripts /usr/local/freeswitch/storage /usr/local/freeswitch/recordings /etc/fusionpbx /usr/local/freeswitch/conf /usr/local/freeswitch/sounds/music/

Para salvar o arquivo, pressione ctrl + x e depois y para salvá-lo.

Você deve ter o script pronto para executar. (Por padrão, o script usará os caminhos dos pacotes do FreeSWITCH. Se você tiver uma instalação mais antiga usando fonte, certifique-se de alterar isso comentando a linha do pacote #22 e descomentando a linha da fonte #25.)

Crontab (opcional)

Arquivos em /etc/cron.daily serão executados automaticamente se não tiverem uma extensão como .sh. Por esse motivo, o script de backup foi renomeado de fusionpbx-backup.sh para fusionpbx-backup e então é executado todas as noites sem a necessidade de usar crontab.

Configurando crontab -e

    crontab -e
    Escolha 1 para nano
    Vá para a última linha em branco e cole a próxima linha.
    0 0 * * * /bin/sh /etc/cron.daily/fusionpbx-backup.sh
    pressione enter, depois salve e saia.

Depois de concluído, você terá o backup pronto para ser executado com ./fusionpbx-backup ou a partir do cron job diário.
